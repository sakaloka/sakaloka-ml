# SakaLoka ML

Machine Learning component of **[SakaLoka](https://github.com/sakaloka)** — an Indonesia Culture-Based Smart Map.

## Recommendation System

SakaLoka ML provides personalized recommendations for cultural events and destinations using:

* **Content-Based Filtering**
* **Collaborative Filtering**

## Structure

```text
model/          # ML models
rating_based/   # Rating-based recommendation
event.csv       # Event dataset
model.py        # Recommendation model
main.py         # ML API
```
